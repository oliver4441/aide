# Aide Prototype

Original Stitch prototype for Beauty Hub Salon Manager.

## Screens

- **Manager Login** - Desktop & Mobile authentication
- **Dashboard** - Business metrics and analytics
- **New Sale** - Point of sale interface
- **Inventory** - Product management
- **Reports** - Business analytics
- **Settings** - Configuration
- **Receipt** - PDF receipt preview
- **Landing Page** - Marketing page

## Design System: Ethereal Precision

- **Primary**: Berry Plum (#8b3d67)
- **Fonts**: Manrope (headlines), Inter (body), JetBrains Mono (labels)
- **Style**: Corporate Modernism + Minimalism
